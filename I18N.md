# PedigrAPP internationalization (ES/EN)

PedigrAPP is one bilingual application, using Spanish (`es`) and English (`en`) without machine-translation services. UI language must never change clinical data, relationship identifiers, layout, or Undo/Redo history.

## Sources and runtime

- `locales/es.json` and `locales/en.json` are the editable dictionaries; maintain identical semantic keys and matching placeholders.
- `locales/catalog.js` is generated from those files and loaded before dynamic UI is built.
- `i18n.js` provides translation and language-switching functions.
- HTML uses `data-i18n`, `data-i18n-title`, `data-i18n-placeholder`, and `data-i18n-aria-label`. Dynamic JavaScript uses `t(key, params)`.
- Strings entered by users (names, phenotypes, clinical notes and identifiers) are stored data; never translate them automatically.

## Changing a string

1. Add or update the key in **both** language dictionaries and preserve interpolation placeholders.
2. Update visible text in the application, Help, tooltips, warnings and PDF/export interfaces as applicable.
3. Regenerate the bundled catalogue:

```bash
python3 scripts/build_locale_bundle.py
```

4. Review Spanish → English → Spanish with relevant menus and unsaved forms open. Audit findings may include technical false positives; do not blindly rewrite baselines to suppress warnings.
5. Update the in-app Help release history, `CHANGELOG.md`, and `README.md` if a feature or release changes.

Translation source keys, quality-check terminology and clinical symbols should follow the nomenclature references in the Help and `THIRD_PARTY_NOTICES.md`.
