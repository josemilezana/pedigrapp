# Privacy — GitHub Pages edition v1.3

Cases are stored in localStorage in the current browser profile. PedigrAPP does not send case records to a PHP API or other case-storage service in this edition. The hosting provider receives ordinary page requests, including connection metadata. External links open third-party sites under their own policies.

Local storage is not encrypted by this application. Other users of the browser profile and scripts on the same origin may access it. Clearing site data may erase cases. Export JSON backups and verify all exports before sharing: names, annotations and pedigree geometry may identify families.

Do not enter identifiable clinical data into the public demonstration. Clinical use requires an independently assessed, controlled deployment and appropriate authorization, access controls and safeguards. See TERMS_OF_USE.md and SECURITY.md.
